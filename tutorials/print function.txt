ColorFX – Professional Python Terminal Styling Guide (One-Page)

ColorFX is a complete terminal styling system built with ANSI escape codes. It allows you to add colors, background colors, bold, underline, blinking, reverse effects, and ready-made styled messages like errors, warnings, success, banners, and hacker-style outputs — all from a single Python file.

This system works in:

* Windows Terminal
* VS Code Terminal
* Linux terminals
* macOS terminals

It may not work correctly in very old Windows CMD without ANSI support.

---

1. TEXT FORMATTING CODES (Control How Text Looks)

---

FMTRESET
Resets everything back to normal. This is the most important code. If you forget this, your terminal may stay colored.

FMTBOLD
Makes text bold and brighter.

FMTDIM
Makes text darker and faded.

FMTITALIC
Italic style (may not work in all terminals).

FMTUNDER
Underline text.

FMTBLINK
Blinking text (supported only in some terminals).

FMTREVERSE
Swaps background and text colors.

FMTHIDDEN
Hides the text (useful for password effects).

Usage idea:
Use formatting before your text and always end with FMTRESET.
