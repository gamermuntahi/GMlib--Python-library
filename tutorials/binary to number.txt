1. MAIN FUNCTION

binary_to_decimal(binary_str)

Converts a binary string (like "1011") to its decimal equivalent.

Only accepts 0 and 1 characters.

Returns an integer.

Usage Idea:
Use this function in:

Binary calculators

Digital electronics simulations

Learning and teaching binary arithmetic

Converting user input for logic gate operations

2. INPUT REQUIREMENTS

Input must be a string.

Only '0' and '1' are allowed.

Any invalid input raises a ValueError.

Example:

binary_to_decimal("1010")  # Returns 10
binary_to_decimal("111")   # Returns 7
binary_to_decimal("2")     # Raises ValueError

3. HOW IT WORKS

The function iterates from the least significant bit (rightmost) to the most significant bit.

Each bit is multiplied by 2 raised to its position index.

All contributions are summed to give the decimal number.

Algorithm Steps:

Validate input.

Initialize decimal = 0.

Loop over each bit from right to left.

Add bit * (2 ** position) to decimal.

Return decimal.
