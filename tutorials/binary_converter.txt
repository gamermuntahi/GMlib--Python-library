1. WHAT THIS MODULE DOES

binary_converter.py provides two main functions:

convert(value)

Automatically detects what the user typed:

Input Type	Meaning	Output
"1011"	Binary string	11 (decimal)
"29"	Decimal string	29
1011 (int)	Decimal number	1011
11	Decimal	11

It intelligently decides:

If input looks binary → convert to decimal

If input is normal number → return decimal

If input is integer → return integer

to_binary(n)

Converts any integer into a proper binary string:

Input	Output
5	"101"
12	"1100"
255	"11111111"
0	"0"

Supports negative numbers:

to_binary(-5) → "-101"

2. HOW IT WORKS INTERNALLY
Binary → Decimal Conversion Algorithm

Checks if all characters are 0 or 1

Converts using Python base-2 logic:

int(binary_string, 2)


Returns clean decimal integer

Decimal → Binary Conversion Algorithm

For negative numbers, keeps track of sign

Uses Python’s binary engine:

bin(n)[2:]


Removes the 0b prefix

Returns clean binary string

3. FUNCTIONS IN THE FILE

Here is the exact file you received:

def convert(value):
    value = str(value).strip()

    if all(c in "01" for c in value):
        return int(value, 2)

    return int(value)


def to_binary(n):
    n = int(n)

    if n < 0:
        return "-" + bin(n)[3:]  

    return bin(n)[2:]

4. HOW TO USE IT
Convert input to number
import GMlib.binary_converter as cn

x = cn.convert("1011")  
print(x)  
# Output: 11

Convert decimal to binary
print(cn.to_binary(15))
# Output: 1111

Inside Logic Gate Calculator
import GMlib.boolean_algebra_logic_gates as logic
import GMlib.binary_converter as cn

a = cn.convert("1010")
b = cn.convert("0101")

result = logic.binary_add(a, b)
print(cn.to_binary(result))
