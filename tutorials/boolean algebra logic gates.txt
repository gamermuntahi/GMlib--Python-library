BooleanAlgebra – Professional Binary Logic & Arithmetic Guide (One-Page)

BooleanAlgebra is a complete Python module for binary logic gates and binary arithmetic. It allows you to perform bitwise operations, create logic circuits, and compute binary addition, subtraction, multiplication, and division — all using 0 and 1 with logic gates.

This system works in:

Windows Terminal

VS Code Terminal

Linux terminals

macOS terminals

It is fully Python-based, so no external libraries are needed.

1. LOGIC GATES (Fundamental Operations)

AND(a, b)
Returns logical AND of two bits (0 or 1).

OR(a, b)
Returns logical OR of two bits.

NOT(a)
Returns logical NOT of a bit.

NAND(a, b)
Returns logical NAND of two bits.

NOR(a, b)
Returns logical NOR of two bits.

XOR(a, b)
Returns logical XOR of two bits.

XNOR(a, b)
Returns logical XNOR of two bits.

Usage Idea:
Use these functions to simulate digital circuits or build more complex operations.

2. BINARY ADDITION

full_adder_bit(a, b, carry)
Adds two bits and a carry bit. Returns (sum, carry_out).

binary_add(a, b)
Adds two binary numbers (strings like "101" and "11") of any length.

Example:

binary_add("101", "11")  # Returns "1000"

3. BINARY SUBTRACTION

binary_subtract(a, b)
Subtracts b from a using two’s complement. Inputs are binary strings.

Example:

binary_subtract("101", "11")  # Returns "10"

4. BINARY MULTIPLICATION

binary_multiply(a, b)
Multiplies two binary numbers using repeated addition logic.

Example:

binary_multiply("101", "11")  # Returns "1111"

5. BINARY DIVISION

binary_divide(dividend, divisor)
Performs binary division. Returns (quotient, remainder) as strings.

Example:

binary_divide("1101", "11")  # Returns ("10", "1")
